Italian Radar DPC SRI product¶

Live-updated composite Weather Radar Surface Rainfall Intensity (SRI) precipitation product (mm/h), providing continuous spatial coverage over the Italian peninsula from 2010 to the present.

The dataset is stored in Zarr format with a pre-allocated time dimension spanning 2010–2050. Only a subset of this range contains valid observations; all remaining time steps are filled with NaN values. The temporal extent of valid data is demarcated by the last_valid attribute of the Zarr dataset: all time steps up to and including this timestamp contain valid observations, while all subsequent time steps are empty. Consumers of this dataset should query this attribute to determine the current data availability before performing any analysis. Note also that the spacing of the time axis is not constant over the whole archive (for example the Italian radar products moved from a 10-minute to a 5-minute cadence in July 2018), so never compute a position from the start of the series and a nominal step: always look timestamps up on the time coordinate, e.g. ds.sel(time=ds.attrs['last_valid']) or ds.indexes['time'].get_loc(...).

var_name = "RR"

# Cartopy projection from the dataset's CF grid mapping
gm = ds[ds[var_name].grid_mapping].attrs
data_crs = ccrs.TransverseMercator(
    central_longitude=gm["longitude_of_central_meridian"],
    central_latitude=gm["latitude_of_projection_origin"],
    scale_factor=gm["scale_factor_at_central_meridian"],
    false_easting=gm["false_easting"],
    false_northing=gm["false_northing"],
)

g = ds[var_name].sel(time=['2026-08-17T13:00', '2026-08-17T14:00', '2026-08-17T15:00']).plot(
    col="time", transform=data_crs, subplot_kws={"projection": data_crs},
    cmap=cmap, norm=SymLogNorm(0.1, vmin=0.1, vmax=50),
)
for ax in g.axs.flat:
    ax.coastlines("50m")
