OPERA + Italian Radar DPC merged VMI product¶

Live-updated Vertical Maximum Intensity (VMI) radar mosaic merging the European Weather Radar Network (OPERA) composite with the Italian Department of Civil Protection (DPC) national composite, covering Europe at 2 km / 5 min resolution from July 2024 to the present.

The dataset is stored in Zarr format with a pre-allocated time dimension spanning 2018–2050. Only a subset of this range contains valid observations; all remaining time steps are filled with NaN values. The temporal extent of valid data is demarcated by the last_valid attribute of the Zarr dataset: all time steps up to and including this timestamp contain valid observations, while all subsequent time steps are empty. Consumers of this dataset should query this attribute to determine the current data availability before performing any analysis. Note also that the spacing of the time axis is not constant over the whole archive (for example the Italian radar products moved from a 10-minute to a 5-minute cadence in July 2018), so never compute a position from the start of the series and a nominal step: always look timestamps up on the time coordinate, e.g. ds.sel(time=ds.attrs['last_valid']) or ds.indexes['time'].get_loc(...).

var_name = "vmi"

# Cartopy projection from the dataset's CF grid mapping
gm = ds[ds[var_name].grid_mapping].attrs
data_crs = ccrs.LambertAzimuthalEqualArea(
    central_longitude=gm["longitude_of_projection_origin"],
    central_latitude=gm["latitude_of_projection_origin"],
    false_easting=gm["false_easting"],
    false_northing=gm["false_northing"],
)

# every 4th pixel keeps the plot light
g = ds[var_name].sel(time=['2026-08-17T13:00', '2026-08-17T14:00', '2026-08-17T15:00']).isel(x=slice(None, None, 4), y=slice(None, None, 4)).plot(
    col="time", transform=data_crs, subplot_kws={"projection": data_crs},
    cmap=cmap, vmin=0, vmax=60,
)
for ax in g.axs.flat:
    ax.coastlines("50m")
