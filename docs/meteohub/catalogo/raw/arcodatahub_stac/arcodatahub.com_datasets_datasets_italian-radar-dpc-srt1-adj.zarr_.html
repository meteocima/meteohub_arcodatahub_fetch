Italian Radar DPC SRT1_adj product¶

Live-updated composite Weather Radar 1-hour precipitation accumulation (SRT1_adj, mm): the radar rain estimate accumulated over the hour ending at each time stamp and adjusted with the national rain-gauge network, covering the Italian peninsula from July 2018 to the present.

The dataset is stored in Zarr format. The time dimension lists the historical time steps that contain data (one per hour until 2020-07-01 08:00, every 5 minutes from 2020-07-01 08:55) and is pre-allocated every 5 minutes until 2050 for the live updates: all time steps up to and including the last_valid attribute of the Zarr dataset contain observations, while all subsequent time steps are empty. Consumers of this dataset should query this attribute to determine the current data availability before performing any analysis. Because the spacing of the time axis is not constant, never compute a position from the start of the series and a nominal step: always look timestamps up on the time coordinate, e.g. ds.sel(time=ds.attrs['last_valid']) or ds.indexes['time'].get_loc(...). Areas outside the radar coverage are NaN (-9999 in the raw data); 0 means no rain.

var_name = "srt1_adj"

# Cartopy projection from the dataset's CF grid mapping
gm = ds[ds[var_name].grid_mapping].attrs
data_crs = ccrs.TransverseMercator(
    central_longitude=gm["longitude_of_central_meridian"],
    central_latitude=gm["latitude_of_projection_origin"],
    scale_factor=gm["scale_factor_at_central_meridian"],
    false_easting=gm["false_easting"],
    false_northing=gm["false_northing"],
)

g = ds[var_name].sel(time=['2026-08-17T13:00', '2026-08-17T14:00', '2026-08-17T15:00']).plot(
    col="time", transform=data_crs, subplot_kws={"projection": data_crs},
    cmap=cmap, norm=SymLogNorm(0.1, vmin=0.1, vmax=50),
)
for ax in g.axs.flat:
    ax.coastlines("50m")
